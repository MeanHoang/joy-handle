# 📊 Joy — Feature Hub

Nơi quản lý **spec đã lọc** và **pha quy trình** của từng feature Joy.
Nguồn rác (Notion thô, ticket, chat) gom về đây → lọc sạch → BA & team đọc 1 chỗ.

> **Quy tắc vàng**
> - Spec ở đây là **đầu vào** (build *cái gì*), KHÔNG mô tả code đang chạy sao.
> - Sự thật về code & "đã code xong gì" luôn nằm ở **repo Joy + git/MR**.
> - File này chỉ theo dõi **pha quy trình**, không ghi tay checklist code.
